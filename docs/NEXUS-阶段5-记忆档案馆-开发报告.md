> 依据：《NEXUS 游戏项目永久开发总规范 V1.0》+ 阶段 4 开发报告
> 范围：只新增记忆档案馆（剧情收藏系统）与碎片归档链路；后续章节、Boss 未改动。
> 完成日期：2026-11-05

## 一、交付概览

| 交付项 | 内容 |
|---|---|
| 独立档案馆界面 | 新增 `VaultPage`（主菜单「◇ 创世主记忆档案馆」），全息展厅 + 六槽位 |
| 六枚碎片 | 按故事顺序 01~06，未收集显示加密态（██████ + 🔒） |
| 独立详情页 | 已收集碎片可打开：副标题 / 引文 / 完整剧情 / 归档时间 / 状态 |
| 恩格尔记忆影像 | 每枚碎片 + 最终档案都有专属记忆台词，可播放（CinematicStage 演出） |
| 收集动画 | 新增 `FragmentGain`：全息核心生成 + 旋转环 + 扫描线 + 名称/引文浮现，首杀时播放 |
| 最终记忆档案 | 六枚齐备解锁《超越起源》，含完整剧情与影像 |
| 归档记录 | `meta.fragmentLog`（获取时间）+ `progress.vault`（已阅/最终档案/上次浏览） |
| 恢复浏览 | 关闭页面后重进，自动恢复上次查看的碎片 |
| 主线事件回顾 | 已解锁事件可回放（序章 / 第一~二章 / Boss 战），回放不改变进度 |
| 防重复领取 | `canReceiveFragment` + `completeBoss` 幂等 |

## 二、10 项设计要求对照

| # | 要求 | 实现 |
|---|---|---|
| 1 | 全息档案馆界面 | 旋转全息环 + 扫描线 + 六槽位发光卡片 |
| 2 | 按故事顺序排列 | 01 初始指令 → 06 起源之外，槽位为 `frag-01..06` 顺序 |
| 3 | 未收集显示加密 | `██████` + 🔒 + 「加密状态」，点击提示对应章节 |
| 4 | 独立详情页 | 标题 / 副标题 / 引文 / 完整剧情 / 归档时间 / 状态 / 操作按钮 |
| 5 | 恩格尔记忆影像 + 完整剧情 | 每枚 4 段剧情 + 3 句恩格尔记忆，可播放 |
| 6 | 收集动画 | `FragmentGain`（首杀时触发，点击可跳过） |
| 7 | 六枚齐备解锁最终档案 | `finalMemoryUnlocked()` → 《超越起源》 |
| 8 | 记录获取状态 | `fragmentLog[id] = 时间戳`（旧档补 0 = 早期归档） |
| 9 | 关闭页面后恢复 | 已阅 / 上次浏览写入 `progress.vault`，重进自动恢复 |
| 10 | 不允许重复领取 | `completeBoss` 检查 `bossesDone`，`canReceiveFragment` 兜底；旧 id 同样视为已拥有 |

**定位**：档案仅展示剧情、不售卖任何物品，与兑换中心完全分离。

## 四、主线事件回顾

- 事件源：`lore/events.ts` 的 14 个事件；有演出脚本的事件才显示「回放」。
- 回放映射：`lore/replay.ts`
  - 序章 / 第一章 / 第二章 → 对应章节全部演出场景
  - 训练完成 / 第三~六章 → 台词序列（DialogSystem）
  - GATE-01 / SOMNIA → 战前 + 战后演出
- 回放为**只读模式**：不写阅读次数、不解锁事件、不改变任何进度。
