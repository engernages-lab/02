# NEXUS V1.3 · 竞赛演示脚本

- 演示总时长：约 7 分钟（可压缩到 5 分钟，也可扩展到 8 分钟）
- 演示模式：真实游戏 + 预制 Demo Save
- 禁止：修改正式玩家存档、使用开发调试面板、伪造成就/奖励

## 0. 演示前准备

### 0.1 两份 Demo Save

| 文件 | 用途 |
|---|---|
| `docs/competition/demo-challenge-save.json` | 第一幕代码修复（Lv.1，训练终端未通关） |
| `docs/competition/demo-save.json` | Boss / Explore / Profile（Lv.5，第一章已修复，Boss 待挑战） |

推荐使用独立的 Chrome Profile 或独立浏览器窗口，避免覆盖正式存档。

### 0.2 导入方式

1. 打开游戏并进入主菜单。
2. 系统配置 → 导入存档 → 选择对应 Demo Save JSON。
3. 导入会覆盖当前进度；正式存档请先导出备份。
4. 刷新页面，确认主菜单显示预期等级。

### 0.3 演示前检查

- 生产构建已启动：`npm run build` 后 `npm run serve`。
- 页面已预加载一次，避免首次 Chunk / 字体 Loading。
- Python Runtime 已预热；挑战页可打开。
- 浏览器缩放 100%，分辨率 1440×900 或同比例。
- 通知/输入法弹窗关闭。
- 准备备用截图目录：`docs/competition/screenshots/`。

## 7. 时间压缩方案（5 分钟）

- Boss 战只展示 Phase 1 → Phase Transition → 最终 Victory（跳过重复防御）。
- Explore 只展示区域与隐藏信号。
- MIRA 只展示页面与一条记忆。
- 启动握手直接点击“跳过初始化”。

## 8. 风险与备用方案

| 风险 | 备用方案 |
|---|---|
| Python Runtime 首次加载慢 | 演示前预热一次；或直接展示预生成结算截图 |
| 首次 Chunk 加载出现 Loading | 演示前每页预加载一次；Loading 本身可作为 NEXUS 设计展示 |
| Boss 攻击打断讲解 | 提前防御；或直接展示已准备好的 Boss 截图 |
| 浏览器存档被覆盖 | 使用独立 Profile；正式存档先导出备份 |
| 字体网络慢 | 使用本地已缓存环境；准备截图包 |
| 操作失误 | 可刷新后重新导入 Demo Save |
| 演示时间不足 | 使用 5 分钟压缩方案，跳过 MIRA/探索细节 |

## 9. Demo Save 恢复 / 删除

- 恢复：系统配置 → 导入存档 → 选择对应 JSON。
- 备份：系统配置 → 导出 JSON。
- 删除：系统配置导入一个全新存档，或在浏览器控制台执行：
  `localStorage.removeItem('nexus_code_repair_save_v1')`，然后刷新。
- 详细说明：`docs/competition/DEMO-SAVE.md`
