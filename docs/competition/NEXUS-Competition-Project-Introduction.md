# NEXUS 竞赛项目简介

## 1. 项目名称

《代码修复局：NEXUS 虚拟终端故障营救》

## 2. 项目定位

一款以真实 Python 代码修复为核心玩法的科幻叙事编程游戏。玩家扮演硅灵修复师 R-07，在崩坏的 NEXUS 数字世界中修复故障、探索服务器、挑战章节 Boss，并与智能伙伴 MIRA 一起追查五年前的事故真相。

## 3. 项目背景

传统编程学习常见问题是“会做题，但没有沉浸感”。NEXUS 把代码错误包装成数字世界中的故障事件，让玩家在剧情、战斗与探索中完成真实 Python 判题，而不是做孤立的语法练习。

## 4. 项目目标

- 让 Python 学习与游戏目标自然绑定。
- 用真实 Judge 验证每一次修复，不做伪选择。
- 用 Boss、MIRA、探索与成长形成完整游戏闭环。
- 保持纯前端、本地可运行、可离线演示。

## 5. 游戏世界观

NEXUS 是承载人类数字文明的核心网络。五年前的事故让六个服务器区域接连损坏，创世主留下六枚记忆碎片。玩家作为修复师进入数字世界，修复异常程序、回收记忆，并逐步接近事故真相。

## 6. 核心玩法

- **Challenge**：阅读故障日志、修改 Python 代码、运行与提交，真实测试通过才算修复。
- **Boss**：阶段化战斗，包含攻击预警、弱点破解、动态危机与阶段转换；判题通过才造成伤害。
- **MIRA**：会升级、记忆、诊断与提示的智能伙伴。
- **Explore**：服务器区域、探索节点、遗迹、隐藏信号与终端挑战。
- **Growth / Risk**：等级、经验、称号、容错、意识、风险与成就。
- **Economy / Save**：贡献点、奖励流水、商店与 Save v10 持久化。

## 7. 核心创新

1. 真实代码判题与游戏结算同源。
2. Boss 战把编程能力考试转化为多阶段战斗。
3. MIRA 的记忆与反馈来自真实事件，而非固定展示。
4. 探索奖励、成就、MIRA、成长共用同一份 PlayerState。
5. 页面级懒加载、Error Boundary 与自愈存档保证演示稳定性。

## 8. 技术架构

- React 18 + TypeScript + Vite。
- 自定义 Rollup 生产构建，ESM 页面级 Code Splitting。
- 纯前端本地 MicroPython / Python Runtime 判题。
- Monaco 编辑器。
- 中央 gameStore + 纯逻辑引擎模块。
- Save v10：字段级 normalize、自愈、旧档兼容。
- 页面级 Suspense Loading + 全局 Error Boundary。

## 9. 用户价值

- 对学习者：真实写代码、即时反馈、有剧情与目标。
- 对教师：可演示、可观察错误类型、可追踪学习过程。
- 对竞赛展示：视觉完整、玩法闭环、技术真实。

## 10. 项目成果

- 完整六章主线与 31 个真实修复关卡。
- 7 个可探索服务器区域。
- 多阶段 Boss 战、弱点、危机、评分、奖励与档案。
- 26 项成就、MIRA 记忆系统、玩家成长与风险系统。
- 3,200+ 项自动化测试/检查通过。
- 生产构建 Initial JS 约 1.17 MB，页面级懒加载。
