# NEXUS 核心创新说明

## 创新一：代码修复游戏化

NEXUS 不把编程题放在游戏旁边，而是把“修 Bug”本身变成游戏事件。

- 每个关卡有故障现象、故障日志、任务目标与知识卡。
- 玩家在真实 Monaco 编辑器里改代码。
- 运行不计数，提交才进入真实 Judge。
- 只有全部测试通过，才完成关卡、获得经验与贡献点。

创新价值：玩家不是在“做练习”，而是在“修复世界”。

## 创新二：Boss 战系统

Boss 战把编程能力考试扩展为多阶段战斗：

- **Phase**：多阶段血量、阶段任务与阶段转换。
- **Attack**：真实预警、防御、闪避、打断与伤害。
- **Weakness**：线索 → 分析 → 代码破解 → 暴露 → 伤害加成。
- **Crisis**：未知入侵等动态事件会锁定战斗，需要真实隔离步骤。
- **Recovery**：阶段恢复、意识、容错与战斗记录。
- **演出**：攻击、阶段、弱点、危机、终端均有独立视觉层。

创新价值：代码能力、反应操作与叙事演出形成同一场战斗。

## 创新三：MIRA 智能伙伴

MIRA 不是静态看板：

- 有等级、XP、阶段与成长条。
- 记忆来自真实挑战、探索、Boss、危机与剧情事件。
- 场景对话读取真实意识、失败次数、Boss 阶段与风险。
- 挑战页提供错误诊断与提示，Boss 页提供只读战斗辅助。
- 记忆可回看、筛选与阅读。

创新价值：陪伴感来自真实游戏状态，而不是预设台词。

## 创新四：数字世界探索

探索把世界地图与游戏系统连接：

- 7 个服务器区域。
- 信号、终端、遗迹、隐藏信号四类节点。
- 终端直接进入真实 Challenge，不复制判题。
- 遗迹与隐藏信号进入探索档案。
- 探索奖励进入既有贡献点、MIRA 与成就体系。

创新价值：探索不是点击领奖，而是通往真实玩法内容的入口。

## 创新五：玩家成长与风险机制

成长与风险统一读取真实 PlayerState：

- 等级、经验、称号、容错。
- 意识完整度。
- 失败次数与风险状态 NORMAL / WARNING / DANGER / CRITICAL。
- 成就、探索、Boss 与 MIRA 汇总。
- 成长总览、风险 pill、挑战 HUD 风险 chip。

创新价值：玩家能理解“当前风险是什么、下一步该做什么”。

## 创新六：真实数据一致性

所有系统共用一份存档：

- Challenge 奖励、Boss 奖励、探索奖励、成就奖励使用同一经济账本。
- MIRA 事件使用 eventId 幂等。
- 探索节点使用 rewardsClaimed 幂等。
- Boss 使用 battleId 防重复奖励。
- 成就重算幂等。
- Save v10 字段级自愈。

创新价值：演示时不会出现“页面显示和真实数据不一致”的断层。

## 创新七：稳定的竞赛演示工程

- 页面级 ESM Code Splitting。
- NEXUS 风格 Loading。
- Chunk 加载失败 Error Boundary 与恢复。
- Reduced Motion 与键盘焦点。
- 生产构建真实 Smoke。
- Demo Save 与独立演示流程。

创新价值：项目不仅“能玩”，还“能稳定展示”。
