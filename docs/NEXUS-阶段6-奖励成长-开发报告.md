## 一、交付概览

| 模块 | 交付 |
|---|---|
| 修复贡献点 | 首通基础 + 首通奖励 + 零失误 + 未用提示 + 评级；**重复通关不再产出资源** |
| 防刷关 | 重复通关基础收益归零，仅「星级提升」给 6/星、上限 2 星的补偿 |
| Boss 章节奖励 | 首次击败章节 Boss 发放贡献点 + 信任度 + 道具 + 称号（按章递增，幂等） |
| 等级成长 | 保留原经验系统；Lv5 / Lv7 / Lv10 自动解锁称号 / 头像框 / 粒子并自动装备 |
| 兑换中心 | 补齐**头像框**两类；原有主题/粒子/称号/扫描器/回滚/档案全部可用 |
| 道具实装 | 代码扫描器（高亮可疑行）、数据回滚（恢复代码快照）真正可用并扣库存 |
| 章节结算 | Boss 胜利面板新增：章节评价 / 经验 / 贡献点 / 碎片 / 知识点表现 / 新解锁 |
| MIRA 信任度 | 关卡与 Boss 真实事件提升；≥50 触发 2 处台词变体；≥75 解锁隐藏记忆 |
| 持久化 | 全部写入 rewards（bossRewards / unlocks / items / skins / equipped / trust）与 meta.fragmentLog |

## 二、贡献点规则（真实结算）

| 来源 | 规则 |
|---|---|
| 首通基础 | `max(15, rewardExp / 3)` |
| 首通奖励 | +30 |
| 零失误 | +10（仅首通） |
| 未用提示 | +10（仅首通） |
| 评级 | S +20 / A +12 / B +6（仅首通） |
| 重复通关 | 基础/首通/评级全部为 0；仅星级提升给 6/星，最多 2 星 |
| Boss 首杀 | 第 1~6 章：120/150/180/220/260/360 贡献点 + 信任度 + 道具 + 称号 |

经验仍只在首通发放；重复通关不再产生经验与基础贡献点。

---

## 三、等级解锁

| 等级 | 解锁 | 效果 |
|---|---|---|
| Lv.5 | 称号 · 中级修复师 | 自动装备到称号槽 |
| Lv.7 | 头像框 · 核心回路 | 状态卡头像框发光（frame-core） |
| Lv.10 | 粒子 · 原初辉光 | 自动装备粒子槽 |

跨级会一次性补齐；已解锁不会重复发放；`rewards.unlocks` 记录发放历史。

## 四、兑换中心与道具

- 新增商品：头像框 · 青铜回路（70）、头像框 · 霓虹脉冲（130）。
- 装备生效：头像框在状态卡上真实改变样式；称号优先显示已装备称号。
- **扫描器**（消耗 1）：标出与初始版本不同的行（最多 3 行），只定位不给答案。
- **回滚模块**（消耗 1）：恢复到上一次代码快照（最多保留 12 份）。
- 两者均在挑战页工具栏显示剩余数量，库存不足时阻止使用并提示。

- 知识点表现（该章全部知识点，已掌握标 ✓）

## 九、已知限制

1. 章节结算目前只在多阶段 Boss 战（第一~二章）展示；旧版单题挑战的章节尚未实装。
2. 外观生效范围：头像框与称号已真实生效；终端主题 / 粒子 / 地图背景仍为库存记录。
3. 信任度台词变体目前 2 处，未做分支树（符合规范「不需要复杂好感度树」）。
4. 未新增存档版本：新字段均为可选并由字段级自愈补齐，无需迁移。
