## 一、数字世界地图

- 新增节点状态 **RESTORED（完整恢复）**：该章全部普通关卡通关 **且** 章节 Boss 击败后，服务器节点由 ONLINE 升级为 RESTORED。
- 状态与真实数据同步：`chapterByServer(id)` + `progress.bossesDone`；未解锁仍是 LOCKED / SEALED，半通仍是 DAMAGED。
- 视觉：绿色光晕 + 右上角 ✓ 标记，地图 chips 文案 RESTORED。

## 二、剧情时间线

独立页面「探索档案 · 剧情时间线」（主菜单入口），按故事顺序记录：

| 分类 | 数据来源 | 未解锁表现 |
|---|---|---|
| 主线事件 | `story.unlocked` / 台词节点已读 | 「尚未抵达的事件」 |
| 恩格尔记忆 | 六枚碎片 + `fragmentLog` 时间 | 「第 N 枚碎片 · 未归档」 |
| R-07 成长 | 等级 1~10 + 成就 | 「未达成」 |
| MIRA 记忆恢复 | 碎片数量分阶段（0/2/4/6） | 未达阶段不出现 |

未解锁内容**不泄露真相**：只显示占位与条件，不显示标题正文。

## 三、章节知识复盘

Boss 战结算面板扩展为学习报告：

- 本章知识点（逐项 ✓ / 未掌握）
- 关卡完成情况（章节结算已有的评价与星级）
- **正确率**（本章星级 / 满星）
- **常见错误**（该章 Bug 图鉴中遭遇次数 Top 3）
- **Boss 各阶段表现**（`phaseMask` 逐阶段「已突破 / 未突破」）
- **尚未掌握的知识点**
- **补充练习入口**（跳转编程实验室）

## 四、Bug 图鉴

- 12 条词条，覆盖 SyntaxError / IndentationError / NameError / TypeError / IndexError / KeyError / ValueError / 逻辑错误。
- 每条绑定真实课程关卡（1-1 … 5-2），含现象、成因、修复要点。
- 提交失败时按异常类型自动记入 `meta.bugCodex`（次数 + 首次时间）；未遭遇保持「？？？」加密。
- 图鉴按遭遇次数排序、显示次数条与关联关卡。

## 七、已知限制

1. 地图 RESTORED 只对已实装章节（第一、二章）可能触发，后续章节仍为 SEALED。
2. 时间线按事件顺序而非真实时间排序（存档未记录事件时间戳）。
3. 补充练习按钮跳转实验室，未做按知识点自动筛选的题单。
4. 图鉴目前覆盖 12 类错误，后续章节可继续扩充。
