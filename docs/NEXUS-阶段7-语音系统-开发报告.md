# NEXUS 第七阶段 · 开发报告
## 角色对话语音播放系统

> 依据：《NEXUS 游戏项目永久开发总规范 V1.0》+ 阶段 6 开发报告
> 范围：语音播放与控制、角色音色、中文音色提示、声波反馈；未改动任何剧情台词。
> 完成日期：2026-11-05

---

## 一、12 项要求对照

| # | 要求 | 实现 |
|---|---|---|
| 1 | 对话框扬声器按钮 | 新增 `VoiceBar`，对话框与演出界面统一使用 |
| 2 | 点击播放当前文字 | 读取当前节点 `fullText`（含玩家称呼替换），不额外改写台词 |
| 3 | 暂停 / 继续 / 停止 | 单键状态机 ▶ / ⏸ / 独立 ⏹ 按钮 |
| 4 | 不允许语音叠加 | `speak()` 内部先 `cancel()` 再朗读，同一时刻只有一段 |
| 5 | 进入下一段处理上一段 | 推进 / 跳过 / 卸载均调用 `speech.stop()` |
| 6 | 跳过剧情立即停止 | `skipAll` 先停语音再结束演出 |
| 7 | 全局语音开关 | `settings.voice.enabled`（设置页 + 关闭时按钮禁用） |
| 8 | 自动 / 手动朗读 | `voice.autoRead`；打字完成后自动朗读，或手动点击 |
| 9 | 音量 / 语速 / 音调 | 设置页滑杆，独立于音乐/音效音量 |
| 10 | 音色选择 | 按角色指定音色（`roleVoices`），中文优先排序 |
| 11 | 动态声波 | 播放中 3 根波形柱动画，暂停时冻结 |
| 12 | 保存语音设置 | 写入 `settings.voice`，随存档持久化 |

**保底**：浏览器不支持 / 无中文音色 / 语音失败时，只在界面提示，**不阻断文字剧情**。

## 二、角色语音风格

| 角色 | rate | pitch | 风格 |
|---|---|---|---|
| MIRA | 0.98 | 1.18 | 温柔、理性、略高音 |
| 恩格尔 | 0.92 | 0.94 | 成熟、温和、沉稳 |
| K-0 | 0.86 | 0.55 | 机械、低沉、冷静、压迫 |
| R-07 | 1.00 | 1.06 | 玩家本人（按浏览器可用音色） |
| 系统 / ECHO / 旁白 | — | — | 机械、压迫、平稳 |

音色选择策略：优先 `zh-*`；再按角色性别关键词启发式匹配；最后按角色索引分配，保证尽量不重复。

## 三、健壮性处理

- **不支持语音合成**：按钮禁用 + 标题提示「当前浏览器不支持语音」，文字照常推进。
- **音色未加载**：首次播放给出提示（系统音色是异步加载的）。
- **无中文音色**：首次播放 toast 提示「可在系统里安装中文语音包」。
- **不朗读执行日志**：语音只绑定剧情节点，挑战页终端与调试信息完全静音。
- **不冲突**：语音状态与对话推进解耦；暂停中点击对话仍可继续剧情。
- **音量独立**：`voice.volume` 与音乐/音效音量互不影响。

## 六、已知限制

1. 音色效果取决于设备/系统安装的语音包，代码无法保证音质。
2. 未做逐字高亮（卡拉 OK 效果），只做整句朗读。
3. 设置页未单独列出「无中文音色」的常驻提示，只在首次播放时 toast（避免打扰）。

## 七、结论

- 12 项语音要求全部落地，播放/暂停/继续/停止/跳过行为经端到端验证。
- 语音与对话推进互不阻塞，无叠加，设置持久化。
- 原有功能无回归，全量 634 条断言通过。
