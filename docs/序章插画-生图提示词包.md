# 序章插画 · 生图提示词包

> 本文件是技能 `generate-scene-assets`（阶段 4-asset）的输入清单。
> **prompt 部分以用户 2026-11-19 指定的版本为准**（下方「权威 prompt」）。
> 当前游戏内画面由 `src/components/SceneArt.tsx` 按同一套构图语言用矢量实现；
> 一旦混元生图工具接通，按下表生成 PNG → 放入 `public/art/` → 在 `SCENE_ART_OVERRIDE` 登记，
> 即自动替换为真实绘制图，演出逻辑无需改动。

## 一、风格契约（双锚点）

**background_style_anchor**
> Epic cyberpunk concept art, cinematic lighting, volumetric mist, deep depth of field, UE5 render quality. Palette: dark teal (#061019 / #42D6D0) as the dominant tone, with **neon orange (#FF6B3D) / magenta (#FF6FA0) as hidden accent light** inside the teal. Composition: 16:9 horizontal, strong low-angle or one-point perspective, colossal scale subjects, layered atmospheric perspective (far fog → mid structures → near pure-black silhouette → foreground greeble). High-density glowing windows, cable bundles, glowing pipes. Bottom 20% kept dark/shadowed as UI text safe area.

**background_negative_anchor**
> 人物群像、写实照片、3D 卡通渲染、扁平矢量插画、线框图/PPT 感、可识别的重复贴图网格、纯色空背景、低质量、模糊、噪点过重、文字、水印、签名、暖色主导、过度饱和

**character_style_anchor**（立绘用）
> 2D 赛博朋克角色立绘，伪厚涂笔触，半身构图，冷调蓝绿环境光 + 面部柔光，边缘有全息辉光；深蓝黑背景与淡雾气，人物居中略偏，纵向构图，留头顶空间

**character_negative_anchor**
> 多人、多余肢体、畸形手指、脸崩、文字、水印、低质量、模糊、3D 渲染感、照片写实、服装与设定不符

## 五、落盘与替换

1. 生成后按上表文件名保存到 `public/art/`（尺寸：背景 1280×720，16:9；立绘 720×1280）。
2. 在 `src/components/SceneArt.tsx` 的 `SCENE_ART_OVERRIDE` 中登记：
   ```ts
   const SCENE_ART_OVERRIDE: Partial<Record<SceneBg, string>> = {
     underground: '/art/scene_pro_underground.png',
     void: '/art/scene_pro_void.png',
     corridor: '/art/scene_pro_corridor.png',
   };
   ```
3. 重新 `npm run build`。矢量画面自动退为兜底，不再参与渲染。
