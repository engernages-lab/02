## 七、部署说明

1. `npm install && npm run build` → 产物在 `dist/`。
2. 将 `dist/` 作为静态站点部署（Nginx / 任意静态托管），**不需要后端**。
3. 必须通过 HTTP(S) 访问（`file://` 下 WASM 与模块加载会失败）；本地预览：`npx serve dist`。
4. `dist/` 必须包含：`assets/game.js`、`micropython/*.wasm`、`monaco/`、各 `*.css`。
5. 存档保存在浏览器 `localStorage` 的 `nexus_code_repair_save_v1`，换域名不共享。
6. 升级版本不会清空存档：迁移链 v1→v6 自动执行。
