## 🚀 快速开始

要求：Node.js ≥ 18（推荐 20+）

```bash
cd nexus-game
npm install          # 安装依赖
npm run dev          # 启动开发服务器（Vite），打开 http://127.0.0.1:5173
```

生产构建（纯 JS 工具链，无需原生二进制）：

```bash
npm run build        # Rollup 打包到 dist/
npm run serve        # 静态预览 http://127.0.0.1:4173
```

> **完全离线运行**：代码编辑器（Monaco）与 Python 运行时（MicroPython）全部内置于 `dist/`，
> 不需要任何外网连接。引擎启动约 14 毫秒（wasm 体积仅 481KB），首次打开即可运行代码。

## 🎮 玩法流程

启动页 → 主菜单 → 序章剧情 → 数字世界地图（新人训练终端 → 语法维修站）
→ 编程挑战页：阅读故障 → 修改代码 → 运行预览（不计数）→ 提交修复（正式判题）

- 提交失败会消耗关卡容错次数；**超过上限**会触发纠错者攻击事件
- 攻击需要完成紧急代码防御（把 `??` 替换成正确的运算符）；两次失败意识 -30%
- 意识降到 0% → 意识崩解 → ORIGIN PROTOCOL 重生（等级/成就/知识保留，当前关卡进度重置）
- 知识点通过知识卡收集；MIRA 提供三层递进提示；设置页可调节动画/音量/打字机速度
- 挑战页「🐞 单步调试」：逐行回放执行轨迹，右侧变量监视器实时显示每一步的变量快照
- 主菜单「编程实验室」：完成训练终端后开放，10 道跨章节练习题 + 自由编辑 + 变量快照，不影响主线进度

## ⚙️ 技术要点

- Python 执行：MicroPython Web Worker（与 UI 隔离），5 秒超时强制终止并重建 Worker；
  模块白名单（math/random/time/statistics/datetime/json），禁用 eval/open/input 等高风险操作
- 判题：真实运行 + 测试注入（输出包含检查 / 函数返回值断言），支持多种正确写法；
  运行不计数、提交才计数；错误行号映射与编辑器高亮
- 安全边界：游戏无法访问服务端数据（无后端）；Pyodide 仅作为受限教学沙箱，未来自由编程将委托服务端隔离执行
